

# SoundWave

基于 C++17 / Qt 6 开发的桌面音乐播放器，支持本地音乐管理与云端音乐访问。

## 功能

- **本地与云端音乐库**：本地歌曲使用 SQLite 持久化存储，云端歌曲通过 HTTP 接口获取，并分别展示在对应列表中。
- **播放控制**：支持播放 / 暂停、上一首 / 下一首、拖动进度条、调节音量。
- **播放模式**：支持循环、随机、单曲三种播放模式。
- **下载歌曲**：将云端歌曲下载到本地，包括音频、封面和歌词，并加入本地音乐库。
- **歌单管理**：支持创建、删除、重命名歌单，以及添加、移动歌曲。
- **收藏**：支持收藏 / 取消收藏歌曲，并在收藏页面单独查看。
- **搜索**：按歌曲名称或作者搜索歌曲，支持实时搜索预览。
- **歌词同步**：解析 LRC 歌词，根据播放进度逐行高亮并滚动。
- **右键菜单**：支持播放、收藏、删除、下载、加入 / 移动到歌单等操作。
- **系统托盘**：支持最小化到系统托盘、双击唤出以及托盘菜单退出。
- **记忆播放**：退出时保存音量、播放位置、播放模式等状态，下次启动自动恢复。
- **定时关闭**：设置倒计时，到达指定时间后自动退出程序。

## 使用说明

### 本地音乐库

直接启动程序即可使用本地音乐库，歌曲导入功能将在后续版本中加入。

### 云端音乐库

如果需要使用云端音乐库：

1. 下载并运行远程服务器：[AudioStreamServer](https://github.com/UuKiTing/AudioStreamServer)
2. 修改程序目录中的 `url.config` 文件，将 `BaseUrl` 修改为远程服务器地址：

```ini
BaseUrl=服务器地址
```

3. 重新启动程序
